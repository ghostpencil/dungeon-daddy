# Open License Attribution Notes

## Purpose

Dungeon Daddy should keep licensing notes explicit because the RPG system is inspired by open tabletop rules.

This file is a planning note, not legal advice.

## Recommended approach

Use a Charge-style core as the rules chassis and write original Dungeon Daddy text for:

- action descriptions
- fallout tables
- ability names
- examples
- setting-specific rules
- prompt text
- UI text
- GM guidance

Use the Resistance Toolbox / Heart / Spire only as design inspiration for emotional fallout patterns unless specific SRD text is clearly licensed for reuse and attribution is included.

Do not copy proprietary game prose, art, brands, trade dress, setting names, classes, callings, beats, fallout examples, or distinctive text.

## Product attribution checklist

Before any public release:

- Confirm Charge SRD license text and required attribution.
- Confirm whether any Resistance Toolbox SRD text was copied or adapted.
- Include all required Creative Commons attribution.
- Keep a `THIRD_PARTY_NOTICES.md` file.
- Keep Dungeon Daddy custom mechanics text original.
- Avoid claiming official compatibility with Heart, Spire, Savage Worlds, or any non-open system unless the applicable license allows that claim.

## Proposed internal notice

```text
Dungeon Daddy uses original rules text inspired by open narrative RPG design patterns. Portions of the rules architecture may be compatible with or inspired by the Charge SRD. Required third-party attributions should be maintained in THIRD_PARTY_NOTICES.md before public release.
```

## AI safety / IP hygiene rule

Do not feed proprietary RPG books, commercial PDFs, or non-open sourcebook text into generation prompts or training workflows.

When using AI to draft game text, provide only Dungeon Daddy original notes and permissively licensed SRD mechanics as source material.
