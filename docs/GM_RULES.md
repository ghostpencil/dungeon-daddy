# Dungeon Daddy — GM Rules Reference

## Core Action Roll

Roll a pool of d6s equal to the action's rating. Take the **highest single die**.

| Highest die | Result |
|---|---|
| 1–3 | Bad outcome — failure or hard consequence |
| 4–5 | Success with consequence |
| 6 | Full success |
| Multiple 6s | Critical success — enhanced effect |

Minimum pool is 1 die even at rating 0.

### Push Yourself
Before rolling, accept 1 stress to add 1 extra die to the pool.

---

## Actions

| Action | Use for |
|---|---|
| **Fight** | Harm, restrain, overpower, defend directly |
| **Move** | Sneak, climb, dodge, flee, traverse danger |
| **Tinker** | Repair, disable, craft, manipulate mechanisms |
| **Study** | Investigate, research, interpret clues, analyze |
| **Focus** | Resist fear, exert will, perform mental discipline |
| **Sway** | Persuade, comfort, deceive, provoke, command socially |
| **Sense** | Read emotions, notice danger, perceive hidden things |
| **Channel** | Interact with magic, visions, spirits, dungeon resonance |
| **Endure** | Withstand pain, exhaustion, poison, sustained pressure |

Action ratings run **0–3**. Rating 0 still contributes (1 die, 17% full success). Rating 3 is powerful (4 dice, 52% full success or crit).

---

## Momentum

Characters gain momentum from strong successes, good positioning, and roleplay hooks. Spend momentum to add dice, improve effect, or activate abilities.

Cap: **6**. Momentum is tracked per actor.

*Note: momentum cap enforcement is deferred to Phase 33. The GM may narrate momentum freely in the current build.*

---

## Stress Tracks

Each PC has four stress tracks, each with **capacity 4**.

| Track | Meaning |
|---|---|
| **Body** | Physical harm, exhaustion, poison, injury |
| **Composure** | Fear, panic, shame, grief, despair |
| **Bonds** | Relationship damage, isolation, distrust |
| **Weird** | Occult contamination, memory bleed, dungeon influence |

When a track fills, evaluate **fallout**.

### Weird Track
Weird is the most consequential track. Filling it always writes dungeon influence tags and a memory entry. Recovery from Weird rarely leaves the character unchanged — the dungeon remembers.

---

## Fallout

Fallout triggers when a stress track fills. Severity escalates with unresolved fallout on the same track:

| Active fallout on track | Severity |
|---|---|
| 0 | Minor |
| 1 | Moderate |
| 2+ | Severe |

**Minor examples:** Battered, Rattled, Distant, Touched  
**Severe examples:** Broken, Broken Down, Severed, Claimed

Fallout is story-generative, not just a penalty. Resolve it through fiction: rest, care, trust-repair, confession, or a cost-laden bargain with the dungeon.

---

## Clocks

Use clocks to track investigation progress, combat objectives, monster resistance, environmental threats, and dungeon influence.

| Size | Use |
|---|---|
| 3 | Simple obstacle or weak monster |
| 4 | Standard obstacle |
| 6 | Major obstacle or dangerous monster |
| 8 | Boss phase or major ritual |

Advance a clock on success. Linked clocks model multi-stage situations.

---

## Recovery

Recovery clears stress but requires a narrative action:

- Rest in a safe room
- Receive care from an ally
- Repair broken trust
- Confess a fear
- Reject (or accept at cost) the dungeon's comfort

There is no hit-point math. Recovery is a scene, not a roll.

---

## NPCs and Monsters

Monsters use a lightweight profile:
- Name, type, threat role
- Resistance/threat clock (3–8 segments)
- Instinct (what they always want)
- Actions and stress they inflict
- Fallout tendencies and tags

No initiative, no armor class, no challenge rating.
